# Kiemtratoan
Kiemtratoan6-9

Chức năng đã hoàn thành:
Giao diện Sidebar - Chọn lớp (6-9), hình thức thi, thanh trượt tỷ lệ động (chỉ hiện khi chọn "Kết hợp"), thời gian/số câu
Logic tạo đề Mock - Ngân hàng câu hỏi mẫu cho cả 4 lớp, tính điểm tổng luôn = 100
Xuất PDF Unicode - Font DejaVu Sans được tự động tải từ GitHub, hỗ trợ tiếng Việt đầy đủ, footer bản quyền "Nguyễn Kim Thu - Trường Phùng Hưng"
Cách chạy:
cd Kiemtratoan
uv sync
uv run streamlit run app.py
Sau khi chạy, truy cập http://localhost:8501 để sử dụng ứng dụng. Chọn cấu hình ở sidebar, bấm "Tạo đề thi", rồi tải PDF.
